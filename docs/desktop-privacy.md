# StoreGate Desktop プライバシーポリシー

適用日 2026年11月24日

StoreGate Desktopは、アプリの配信準備をMacで管理するツールです。StoreGateの運営者は、Desktopから個人情報を収集するサーバーを設けていません。広告、利用状況の分析、トラッキングの機能は組み込んでいません。

## Macに保存する情報

登録したアプリ、配信版、ソース・成果物・掲載素材の場所、作業や実機QAの記録を、MacのStoreGateのデータフォルダに保存します。指定されたファイルの形式・メタデータを検査し、空き容量が不足する場合はビルドを開始しません。検査したファイルのメタデータや空き容量をStoreGateの運営者へ送信することはありません。

## 外部サービスとの通信

公式画面やプライバシーポリシーへのリンクは、選択するとブラウザで開きます。配信対象の照会、原稿URLの到達確認、アップロードなどの操作では、目的に応じてApple、Google、原稿に指定したURLの提供元に通信します。実行する操作に必要な範囲で、アプリの識別子、認証情報、ビルドや掲載素材などを送ります。送信先には、それぞれのサービスのプライバシーポリシーが適用されます。別途登録したビルド・QA等のコマンドの動作は、そのコマンドの設定に従います。

## 保持と削除

作業記録はユーザーがMac上で管理します。削除する場合は、アプリを終了したうえで、必要な記録を退避してから「Application Support」のStoreGateフォルダを削除してください。保存先を変更した場合はそのフォルダを使用します。AppleやGoogleに保存した情報は、各ストアの管理画面で管理してください。

## お問い合わせ

StoreGateの扱うデータについては、公開の場に実機記録や認証情報を書かずにお問い合わせください。[StoreGateの問い合わせ窓口](https://github.com/TaigaShinohara/StoreGate/issues)
